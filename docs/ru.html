Уберите небольшой watermark из угла видео без загрузки файла в онлайн-сервис.

Seedance Watermark Remover — локальное приложение для Windows от Bakhtier Sizhaev. Оно подходит, когда в MP4 осталась маленькая метка в углу: текст, логотип, Gemini-звезда или пометка от генератора видео, а нужен чистый файл на своём компьютере.

Для локальной обработки

Используйте, если нужно убрать водяной знак с видео без онлайн-редакторов и без передачи файла наружу.

Для Windows

Скачайте portable ZIP, распакуйте папку и запустите EXE. Все runtime-файлы и ffmpeg уже внутри.

Для честного результата

Лучше всего работают небольшие статичные отметки в углах. Большие движущиеся наложения могут требовать ручной правки.

Как пользоваться

Три шага. Без настройки.

  1. 1
    Скачайте SeedanceWatermarkRemover-Windows-x64-portable.zip из релиза v1.2.3.
  2. 2
    Распакуйте ZIP и держите файлы одной папкой.
  3. 3
    Запустите SeedanceWatermarkRemover.exe, выберите видео и сохраните чистую копию.

Безопасность

Почему Windows может показать SmartScreen

Это новый open-source EXE для Windows, пока без цифровой подписи. Поэтому SmartScreen может показать “Windows protected your PC” и “Unknown publisher”. Это предупреждение о репутации и подписи, а не подтверждённое обнаружение вируса. Исходный код и сборочный скрипт открыты. Если вы доверяете релизу, нажмите More info → Run anyway или сначала проверьте SHA256.

SHA256 checksums

Скачайте SHA256SUMS.txt со страницы релиза v1.2.3, чтобы проверить portable ZIP и собранный EXE.

План для следующих релизов

Если проект будет распространяться шире, следующий правильный шаг — купить OV/EV сертификат подписи кода и подписывать EXE, чтобы Windows показывал проверенного издателя.

Частые вопросы

Видео куда-то загружается?

Нет. Обработка идёт локально на вашем компьютере.

Удалит любой watermark?

Нет. Приложение рассчитано на небольшие статичные отметки в углах: текст, badge или простой логотип. Сложные движущиеся метки лучше править вручную.

Исходный файл изменится?

Нет. Приложение создаёт новый выходной файл и не перезаписывает исходное видео.

Может ли приложение обновляться само?

Да, в Windows portable EXE. Приложение проверяет GitHub Releases, подсвечивает кнопку обновления, если вышла новая версия, скачивает ZIP после подтверждения и перезапускается через небольшой helper.

Исходный код: в репозитории лежат исходный код приложения, проверки сборки, логотипы и сайт GitHub Pages. Portable ZIP лучше публиковать как файл в GitHub Releases.
