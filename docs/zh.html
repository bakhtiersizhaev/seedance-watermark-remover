适合本地处理

当你想去掉视频角落的小水印，但不想把文件传到在线编辑器时，可以使用它。

适合 Windows 用户

下载 portable ZIP，解压整个文件夹，然后运行 EXE。运行所需文件和 ffmpeg 已经包含在里面。

适合真实预期

它最适合小型静态角落标记。大型、移动或位于画面中心的覆盖物可能仍需要手动编辑。

使用方法

三步开始。不需要复杂配置。

  1. 1
    从 v1.0.1 release 下载 SeedanceWatermarkRemover-Windows-x64-portable.zip。
  2. 2
    解压 ZIP，并保持整个文件夹完整。
  3. 3
    运行 SeedanceWatermarkRemover.exe，选择视频，生成干净副本。

安全提示

为什么 Windows 可能显示 SmartScreen

这是一个新的开源 Windows EXE，目前还没有数字签名。因此 SmartScreen 可能显示 “Windows protected your PC” 和 “Unknown publisher”。这属于 Windows 对新文件和未签名发布者的信誉提示，不等于确认有病毒。源码和构建脚本是公开的。如果你信任这个 release，可以点击 More info → Run anyway，也可以先核对 SHA256。

SHA256 校验值

从 v1.0.1 release 页面下载 SHA256SUMS.txt，用于校验 portable ZIP 和打包后的 EXE。

后续签名计划

如果这个项目面向更多用户发布，下一步应该购买 OV/EV 代码签名证书并签名 EXE，让 Windows 显示已验证的发布者。

常见问题

视频会上传到外部服务吗？

不会。处理在你的 Windows 电脑本地完成。

它能去掉所有水印吗？

不能。它主要用于小型静态角落文字、badge 或简单 logo。复杂移动水印通常需要手动编辑。

会覆盖原视频吗？

不会。工具会生成新的输出文件，原视频保持不变。
