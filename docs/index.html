For local cleanup

Use it when you want to remove a small watermark from a video without sending the file to an online editor.

For Windows users

Download the portable ZIP, extract it, and run the EXE. The release includes the runtime files and ffmpeg.

For realistic results

It works best on small static corner marks. Large moving overlays may still need manual editing.

How to use

Three steps. No setup.

  1. 1
    Download SeedanceWatermarkRemover-Windows-x64-portable.zip from the v1.1.0 release.
  2. 2
    Extract the ZIP and keep the whole folder together.
  3. 3
    Run SeedanceWatermarkRemover.exe, choose your video, and save a clean copy.

Security notice

Why Windows may show SmartScreen

This is a new unsigned open-source Windows executable. Windows SmartScreen can show “Windows protected your PC” and “Unknown publisher” until the app is code-signed or gains reputation. The source code and build script are public. If you trust this release, use More info → Run anyway, or verify the SHA256 checksum first.

SHA256 checksums

Download SHA256SUMS.txt from the v1.1.0 release page to verify the portable ZIP and packaged EXE.

Future signing plan

For a larger public release, the next step is to buy an OV/EV code-signing certificate and sign the EXE so Windows shows a verified publisher.

Before you download

Common questions

Does it upload my video?

No. Processing happens locally on your computer.

Will it remove every watermark?

No. It is made for small static corner text, badges, and simple logo overlays. Complex moving marks can need manual editing.

Does it change the original file?

No. It creates a new output video and leaves the source file untouched.
